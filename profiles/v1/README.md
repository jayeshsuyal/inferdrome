# Managed GPU capability profiles

These documents publish the opt-in Linux/NVIDIA evidence capability separately
from Inferdrome's frozen public bundle schemas.

- `local-gpu-proof.schema.json` is a closed JSON Schema for every field nested
  beneath `native/invocation.json.local_gpu_proof`.
- `managed-vllm-0.26-evidence-profile.json` freezes invocation, NVIDIA query,
  wheel, snapshot, server, cross-artifact, and native TTFT semantics that require
  checks beyond structural JSON Schema.
- `tests/fixtures/profiles/v1` contains positive and mutation vectors. Cases
  distinguish structural-schema validity from whole-profile validity so
  independent consumers can implement the same fail-closed boundary.

All JSON files are generated by `scripts/generate_capability_profiles.py`.
Document digests use ordinary SHA-256 over RFC 8785 canonical JSON bytes; a
document never embeds its own digest. The profile is evidence semantics, not a
new public bundle schema, hardware attestation, or an acceptance verdict.
